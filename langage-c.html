Langage C

Programmes illustrant variables, conditions, boucles, fonctions et pointeurs.

Mini-projet 1 — [notion : variables et conditions]

Description : Le programme demande une note sur 20, vérifie sa validité, puis affiche si l’étudiant est admis (note au moins égale à 10) ou non.

Code source

#include <stdio.h>
int main(void) {
    float note;
    printf("Saisir une note sur 20 : ");
    if (scanf("%f", &note) != 1 || note < 0 || note > 20) {
        printf("Note invalide.\\n");
        return 1;
    }
    if (note >= 10) printf("Résultat : admis.\\n");
    else printf("Résultat : non admis.\\n");
    return 0;
}

Explication

Le programme demande une note sur 20, vérifie sa validité, puis affiche si l’étudiant est admis (note au moins égale à 10) ou non.

Capture d’exécution

Difficultés et solutions

J’ai utilisé scanf avec vérification de sa valeur de retour et une condition if/else. La difficulté est d’éviter de traiter une saisie invalide comme une note valide.

Mini-projet 2 — [notion : boucles et tableaux]

Description : Le programme parcourt un tableau de cinq entiers, calcule leur somme et affiche leur moyenne.

Code source

#include <stdio.h>
int main(void) {
    int valeurs[] = {4, 8, 2, 10, 6};
    int n = sizeof(valeurs) / sizeof(valeurs[0]);
    int somme = 0;
    for (int i = 0; i < n; i++) somme += valeurs[i];
    printf("Somme = %d\\n", somme);
    printf("Moyenne = %.2f\\n", (float)somme / n);
    return 0;
}

Explication

Le programme parcourt un tableau de cinq entiers, calcule leur somme et affiche leur moyenne.

Capture d’exécution

Difficultés et solutions

La boucle for parcourt les indices de 0 à n-1. La taille est calculée avec sizeof pour éviter de coder directement le nombre d’éléments.

Mini-projet 3 — [notion : fonctions et pointeurs]

Description : La fonction echanger reçoit les adresses de deux entiers et échange leurs valeurs en utilisant un pointeur temporaire.

Code source

#include <stdio.h>
void echanger(int *a, int *b) {
    int temporaire = *a;
    *a = *b;
    *b = temporaire;
}
int main(void) {
    int x = 12, y = 5;
    printf("Avant : x=%d, y=%d\\n", x, y);
    echanger(&x, &y);
    printf("Après : x=%d, y=%d\\n", x, y);
    return 0;
}

Explication

La fonction echanger reçoit les adresses de deux entiers et échange leurs valeurs en utilisant un pointeur temporaire.

Capture d’exécution

Difficultés et solutions

La difficulté principale est de distinguer une adresse (&x) de la valeur située à cette adresse (*a).

Comparatif Python / C

Python privilégie une syntaxe concise et une gestion mémoire automatique ; C demande des déclarations de types et donne un contrôle plus direct sur la mémoire.

Comparatif Python / C

CritèrePythonC
SyntaxeCourte ; blocs définis par l’indentation.Types déclarés, accolades et points-virgules.
TypageDynamique.Statique.
MémoireGestion principalement automatique.Contrôle explicite possible avec pointeurs et allocation dynamique.
ExécutionGénéralement exécuté par l’interpréteur Python.Généralement compilé en code machine.

Option — reproduire les démonstrations dans Termux

Les images existantes illustrent les sorties attendues et sont étiquetées comme démonstrations. Si une consigne exige une preuve personnelle, installer le compilateur dans Termux puis lancer chaque programme :
