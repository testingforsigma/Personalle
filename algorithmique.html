Algorithmique

Organigrammes, pseudo-code et traduction en Python/C de trois algorithmes.

Algorithme 1 — Recherche du maximum

Traduction Python :

def maximum(T):
    if not T:
        raise ValueError("Le tableau ne doit pas être vide")
    maxi = T[0]
    for valeur in T[1:]:
        if valeur > maxi:
            maxi = valeur
    return maxi

print(maximum([4, 9, 2, 7]))  # 9

Explication

Le programme initialise le maximum avec le premier élément, puis compare chaque valeur suivante. Il ne remplace le maximum que si une valeur plus grande est trouvée.

Vérification

Le tableau vide doit être traité séparément, car T[0] n’existe pas dans ce cas.

Algorithme 2 — Tri à bulles

Traduction Python :

def tri_bulles(T):
    T = T.copy()
    n = len(T)
    for i in range(n - 1):
        echange = False
        for j in range(n - 1 - i):
            if T[j] > T[j + 1]:
                T[j], T[j + 1] = T[j + 1], T[j]
                echange = True
        if not echange:
            break
    return T

print(tri_bulles([5, 2, 4, 1]))  # [1, 2, 4, 5]

Explication

Le tri compare les éléments voisins et les échange s’ils sont dans le mauvais ordre. Après chaque passage, le plus grand élément restant se place à la fin. L’arrêt anticipé évite des passages inutiles si aucun échange n’a été effectué.

Vérification

Il faut réduire la zone comparée après chaque passage et ne pas dépasser l’indice n-2.

Algorithme 3 — Recherche séquentielle

Traduction Python :

def recherche(T, x):
    for i, valeur in enumerate(T):
        if valeur == x:
            return i
    return -1

print(recherche([8, 3, 5, 1, 9], 1))  # 3
print(recherche([8, 3, 5], 7))        # -1

Explication

La fonction parcourt le tableau dans l’ordre. Elle renvoie immédiatement l’indice dès qu’elle trouve la valeur ; si la boucle se termine, elle renvoie -1.

Vérification

Il faut bien distinguer l’indice (qui commence à 0) de la position humaine (qui commence à 1).

Du pseudo-code au programme Python

  • Maximum : l’initialisation maxi ← T[0] devient maxi = T[0] ; la boucle « pour chaque valeur » devient for valeur in T[1:] ; le test et l’affectation gardent le même sens.
  • Tri à bulles : les deux boucles imbriquées traduisent les passages et comparaisons de voisins. L’échange simultané de Python remplace les trois affectations temporaires souvent écrites en pseudo-code. Le drapeau echange conserve l’arrêt anticipé.
  • Recherche séquentielle : l’indice est parcouru de gauche à droite. enumerate fournit à la fois l’indice et la valeur ; return -1 traduit le cas « non trouvé ».

Ces traductions conservent les idées des algorithmes d’origine : initialisation, parcours, comparaison, échange et condition d’arrêt. Les exemples affichés dans les blocs de code constituent les sorties attendues.
